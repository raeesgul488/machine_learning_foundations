## 📖 Overview

This repository documents my step-by-step progress in learning **Machine Learning**, starting with the Python skills every AI practitioner needs and building toward core ML concepts and models.

The goal is simple: **understand the fundamentals deeply, not just run the code.** Every topic is practiced with small, readable examples so the ideas stay clear.

**This repo is for you if you:**

- 🌱 are a beginner who wants a clear path into AI and ML
- 🐍 want to practice Python specifically for data and AI work
- 📚 like learning by reading and running real code

---

## 🗺️ Learning Path

```text
 Python Basics  ─►  Data Handling  ─►  Visualization  ─►  ML Concepts  ─►  Models & Evaluation
```

| Stage | Focus | Key Ideas |
|:-----:|-------|-----------|
| 1️⃣ | **Python for AI** | Variables, data types, control flow, functions, OOP basics |
| 2️⃣ | **Data Handling** | NumPy arrays, Pandas DataFrames, cleaning and transforming data |
| 3️⃣ | **Data Visualization** | Matplotlib and Seaborn for exploring data |
| 4️⃣ | **ML Concepts** | Supervised vs. unsupervised learning, features, labels, train/test split |
| 5️⃣ | **Models & Evaluation** | Regression, classification, metrics, overfitting vs. underfitting |

> 📌 Stage 1 (**Python for AI**) is the current focus of this repository. Later stages will be added as I progress.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/raeesgul488/machine_learning_foundations.git
cd machine_learning_foundations
```

### 2. Create a virtual environment *(recommended)*

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install the common libraries

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

### 4. Explore the code

```bash
cd Desktop/Python-for-AI
jupyter notebook        # for .ipynb notebooks
# or
python your_script.py   # for .py files
```
